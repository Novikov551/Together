# Подключение к звонку

## Общее описание

После входа в лобби пользователь выбирает комнату, вводит displayName (отображаемое имя) и пароль (если комната приватная). Фронтенд запрашивает у бэкенда LiveKit Access Token, затем подключается к LiveKit Server по WebSocket.

## Полный flow подключения

```
Фронтенд (Lobby)          Backend                 LiveKit Server
    │                        │                          │
    │ 1. POST /api/livekit/  │                          │
    │    token                │                          │
    │    { display_name,      │                          │
    │      room_name,         │                          │
    │      password? }        │                          │
    │ ──────────────────────→ │                          │
    │                        │  2. ValidatePassword     │
    │                        │     roomName, password   │
    │                        │     → SHA256 compare     │
    │                        │  3. Если неверный → 401  │
    │                        │  4. GenerateToken        │
    │                        │     identity =            │
    │                        │       "{name}-{XXXX}"    │
    │                        │     grants =              │
    │                        │       { room_join, room }│
    │                        │     → JWT (AccessToken)  │
    │                        │  5. GetWebSocketUrl      │
    │  { livekit_token,       │                          │
    │    livekit_url }        │                          │
    │ ←────────────────────── │                          │
    │                        │                          │
    │ 6. Room.connect(       │                          │
    │      wsUrl, token)     │                          │
    │ ─────────────────────────────────────────────────→ │
    │                        │                          │  7. Валидация JWT
    │                        │                          │  8. Добавление в комнату
    │ ←───────────────────────────────────────────────── │
    │  9. setMicrophoneEnabled(true)                     │
    │  10. updateParticipants()                          │
```

## Шаги детально

### 1-5. Получение токена

- Бэкенд валидирует пароль (если комната приватная)
- Генерирует `AccessToken` с уникальным identity (`displayName-XXXX`)
- Возвращает JWT + WebSocket URL

### 6. WebSocket подключение

Фронтенд использует `livekit-client`:
```javascript
const room = new Room({
  adaptiveStream: true,
  dynacast: true,
  videoCaptureDefaults: { resolution, maxFps },
  publishDefaults: { videoEncoding, screenShareEncoding },
})
await room.connect(wsUrl, token)
```

### 7-8. LiveKit подключение

- LiveKit валидирует JWT (ApiKey + ApiSecret)
- Создаёт комнату, если не существует
- Добавляет участника в комнату

### 9-10. Инициализация

- Автоматически включается микрофон
- Обновляется список участников

## События Room

После подключения фронтенд слушает:

| Событие | Действие |
|---------|----------|
| `participantConnected` | Звук + обновление списка |
| `participantDisconnected` | Звук + обновление списка |
| `trackSubscribed` | Обновление треков (+ звук если скриншеринг) |
| `trackUnsubscribed` | Обновление треков (+ звук если скриншеринг) |
| `trackMuted` / `trackUnmuted` | Обновление треков |
| `activeSpeakersChanged` | Обновление speaking-индикаторов |
| `isSpeakingChanged` | Per-participant speaking (быстрее) |
| `connectionQualityChanged` | Индикатор качества связи |
| `dataReceived` | Входящее чат-сообщение |
| `disconnected` | Сброс состояния |

## Качество видео

Фронтенд поддерживает пресеты качества:

**Камера:**
| Уровень | Разрешение | Bitrate | FPS |
|---------|-----------|---------|-----|
| low | 360p | 500 kbps | 15 |
| medium | 720p | 1.5 Mbps | 30 |
| high | 1080p | 3 Mbps | 30 |

**Демонстрация экрана:**
| Уровень | Разрешение | Bitrate | FPS |
|---------|-----------|---------|-----|
| low | 1280x720 | 1.5 Mbps | 15 |
| medium | 1920x1080 | 3 Mbps | 30 |
| high | 2560x1440 | 6 Mbps | 30 |
| ultra | 3840x2160 | 12 Mbps | 30 |

Смена качества → перезапуск трека (camera/screen).

## Ping

Измеряется через WebRTC stats каждые 2 секунды:
```javascript
const stats = await pc.getStats()
// ищем candidate-pair с state=succeeded → currentRoundTripTime
```

## Код

- `useRoom.js` — основной хук: Room, треки, чат, quality, ping
- `Lobby.jsx` — экран выбора комнаты
- `JoinModal.jsx` — модалка ввода displayName + пароля
- `Call.jsx` — экран звонка, подключение при монтировании
- `LiveKitController.cs` — endpoint `/api/livekit/token`
- `LiveKitService.cs` — генерация токена, WebSocket URL
