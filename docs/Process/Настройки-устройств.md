# Настройки устройств

## Общее описание

Во время звонка пользователь может переключать устройства (микрофон, камера, динамики) и настраивать качество видео. Настройки сохраняются в `localStorage`.

## Доступные устройства

Фронтенд перечисляет устройства через `navigator.mediaDevices.enumerateDevices()`:

| Тип | Хук | Устройства |
|-----|-----|-----------|
| Аудио вход | `useDevices` | Микрофоны (`audioinput`) |
| Видео вход | `useDevices` | Камеры (`videoinput`) |
| Аудио выход | `useDevices` | Динамики (`audiooutput`) |

## Переключение устройства

```
Пользователь выбирает      useRoom.switchDevice()         LiveKit
другой микрофон                │                            │
    │                          │  room.switchActiveDevice   │
    │ ────────────────────────→│    ('audioinput', deviceId)│
    │                          │ ──────────────────────────→│
    │                          │  Перезапуск трека           │
    │ ←────────────────────────│ ←──────────────────────────│
```

Для камеры аналогично. Для динамиков — через `setSinkId` на всех `<audio>` и `<video>` элементах.

## Настройки аудио

| Настройка | По умолчанию | Описание |
|-----------|-------------|----------|
| `noiseSuppression` | true | Подавление шума |
| `echoCancellation` | true | Подавление эха |
| `autoGainControl` | false | Автоматическая регулировка громкости |

Применяются через перезапуск микрофона с новыми constraints:
```javascript
await room.localParticipant.setMicrophoneEnabled(false)
await room.localParticipant.setMicrophoneEnabled(true, undefined, {
  noiseSuppression, echoCancellation, autoGainControl
})
```

## Качество видео

### Камера

| Уровень | Разрешение | Bitrate | FPS |
|---------|-----------|---------|-----|
| low | 360p (640×360) | 500 kbps | 15 |
| medium | 720p (1280×720) | 1.5 Mbps | 30 |
| high | 1080p (1920×1080) | 3 Mbps | 30 |

### Демонстрация экрана

| Уровень | Разрешение | Bitrate | FPS |
|---------|-----------|---------|-----|
| low | 1280×720 | 1.5 Mbps | 15 |
| medium | 1920×1080 | 3 Mbps | 30 |
| high | 2560×1440 | 6 Mbps | 30 |
| ultra | 3840×2160 | 12 Mbps | 30 |

Смена качества → автоматический перезапуск трека (camera/screen).

## Сохранение настроек

Настройки хранятся в `localStorage` через `useSettings`:
```javascript
{
  cameraQuality: "medium",
  screenQuality: "medium",
  chatSoundEnabled: true,
  avatar: "data:image/..." // base64 аватарка
}
```

## Тест микрофона

`MicTest` компонент — отдельный экран для проверки микрофона перед звонком.

## Код

- `useDevices.js` — перечисление устройств, selected state
- `useSettings.js` — localStorage persistence
- `useRoom.js` — switchDevice, applyAudioSettings, quality presets
- `Controls.jsx` — панель управления (переключение устройств)
- `DeviceSettings.jsx` — модалка настроек
- `CameraPanel.jsx` — настройки камеры
- `ScreenSharePanel.jsx` — настройки скриншеринга
- `MicTest.jsx` — тест микрофона
