# Комнаты

## Общее описание

Комната — это LiveKit Room, в которую участники подключаются для видеозвонка. Комнаты могут быть публичными (без пароля) или приватными (с паролем). Приватность определяется наличием записи в `ConcurrentDictionary` бэкенда.

## Создание комнаты

```
Фронтенд (Lobby)                 Backend                    LiveKit
    │                               │                          │
    │  POST /api/rooms              │                          │
    │  { name, password? }          │                          │
    │ ─────────────────────────────→│                          │
    │                               │  1. Валидация ModelState  │
    │                               │  2. CreateRoom(name)      │
    │                               │ ────────────────────────→ │
    │                               │ ←─ Room ─────────────────│
    │                               │  3. Если password != null │
    │                               │     SHA256(password)      │
    │                               │     _rooms[name] = hash   │
    │  200 OK                       │                          │
    │ ←─────────────────────────────│                          │
```

**Правила:**
- Имя комнаты — произвольная строка
- Пароль опциональный. Если передан — комната становится приватной
- Пароли хранятся как SHA256-хеши в `ConcurrentDictionary`
- Если комната с таким именем уже есть в LiveKit — LiveKit вернёт существующую (не ошибку)
- Если комната уже есть в `_rooms` — повторный `SetPasswordAsync` игнорируется

## Список комнат

```
Фронтенд (Lobby)                 Backend                    LiveKit
    │                               │                          │
    │  GET /api/rooms/all           │                          │
    │ ─────────────────────────────→│                          │
    │                               │  ListRooms()             │
    │                               │ ────────────────────────→ │
    │                               │ ←─ Rooms[] ──────────────│
    │                               │  Фильтр: numPart > 0     │
    │                               │  Для каждой:             │
    │                               │    is_private =           │
    │                               │      _rooms.ContainsKey() │
    │  [{ name, is_private }]       │                          │
    │ ←─────────────────────────────│                          │
```

**Правила:**
- Показываются только комнаты с `num_participants > 0`
- `is_private` определяется наличием в `_rooms` (не из LiveKit)
- Участники подсчитываются отдельным запросом `GetRoomParticipantsAsync`

## Участники комнаты

```
Фронтенд (Lobby)                 Backend                    LiveKit
    │                               │                          │
    │  GET /api/rooms/{room}/       │                          │
    │       participants            │                          │
    │ ─────────────────────────────→│                          │
    │                               │  ListParticipants(room)  │
    │                               │ ────────────────────────→ │
    │                               │ ←─ Participants[] ───────│
    │                               │  .Select(e => e.Name)    │
    │  { name, participants,        │                          │
    │    is_private }               │                          │
    │ ←─────────────────────────────│                          │
```

**Особенности:**
- Если произошла ошибка при получении участников — возвращается пустой список (catch всех Exception)
- ⚠️ `Console.WriteLine` вместо логирования (TODO)

## Удаление комнаты

```
Фронтенд (Call)                  Backend                    LiveKit
    │                               │                          │
    │  DELETE /api/rooms/{room}     │                          │
    │ ─────────────────────────────→│                          │
    │                               │  GetRoomParticipants()   │
    │                               │ ────────────────────────→ │
    │                               │ ←─ Participants[] ───────│
    │                               │  Если participants > 0:  │
    │                               │    return (не удалять)   │
    │                               │  DeleteRoom(room)        │
    │                               │ ────────────────────────→ │
    │                               │  _rooms.TryRemove(room)  │
    │  200 OK                       │                          │
    │ ←─────────────────────────────│                          │
```

**Правила:**
- Удаление только если участников 0 (защита от удаления активной комнаты)
- Фронтенд вызывает `deleteRoom` при `handleLeave` (выход из звонка)
- Если сеть упала — удаление не происходит. LiveKit удалит комнату через `empty_timeout: 60` секунд
- Хеш пароля удаляется из `_rooms` вместе с комнатой

## Время жизни комнаты

| Сценарий | Поведение |
|----------|-----------|
| Последний участник нажал "Выйти" | Фронтенд → DELETE → удалена сразу |
| Сеть упала у последнего участника | LiveKit empty_timeout=60с → удалена через 60с |
| Backend перезапустился | _rooms пуст, хеши потеряны. Комната в LiveKit ещё жива → стала публичной |

- `RoomsController.cs` — endpoints `/api/rooms/*`

- `ILiveKitService.cs` / `LiveKitService.cs` — SDK wrapper
