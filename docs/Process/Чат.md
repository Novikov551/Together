# Чат

## Общее описание

Текстовый чат встроен в видеозвонок и работает через LiveKit Data Channel (WebRTC data channel). Не использует бэкенд — сообщения идут peer-to-peer через SFU.

## Отправка сообщения

```
Отправитель                    LiveKit SFU                 Получатель
    │                              │                            │
    │  publishData({               │                            │
    │    type: "chat",             │                            │
    │    text: "Привет!"           │                            │
    │  }, { reliable: true })      │                            │
    │ ────────────────────────────→│                            │
    │                              │  dataReceived event        │
    │                              │ ──────────────────────────→│
    │  Локально:                   │                            │  JSON.parse
    │  добавить в chatMessages     │                            │  { type: "chat",
    │                              │                            │    text: "Привет!" }
    │                              │                            │  → звук уведомления
    │                              │                            │  → unreadCount++ (если чат закрыт)
```

## Формат сообщения

```json
{
  "type": "chat",
  "text": "Текст сообщения"
}
```

Кодируется через `TextEncoder` → `Uint8Array`, передаётся через `publishData` с `reliable: true`.

## Отображение

Каждое сообщение в UI:
```javascript
{
  id: Date.now() + Math.random(),  // уникальный ID
  sender: "Имя отправителя",        // name или identity
  text: "Текст",
  time: "14:30",                    // локальное время
  isLocal: true/false               // своё или чужое
}
```

## Уведомления

- Входящее сообщение → звук `playChatMessage()` (если `chatSoundEnabled`)
- Если чат закрыт → `unreadCount++`, бейдж на кнопке чата
- Открытие чата → `unreadCount = 0`

## Панель чата

- `ChatPanel` — боковая панель справа
- При открытии чата основная область сжимается (CSS класс `chat-open`)
- Кнопка включения/выключения звука чата
- Кнопка закрытия

## Ограничения

- Нет истории сообщений (только для текущей сессии)
- Нет упоминаний, реакций, форматирования
- Нет индикатора набора текста
- Нет отправки файлов
- Максимальный размер сообщения — не ограничен на уровне приложения (ограничение Data Channel ~256KB)

## Код

- `useRoom.js` — `sendChatMessage`, `dataReceived` handler, `chatMessages` state
- `ChatPanel.jsx` — UI панели чата
- `Call.jsx` — toggle чата, unread count
